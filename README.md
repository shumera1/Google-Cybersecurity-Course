# Google Cybersecurity Certificate

Notes and skills from the [Google Cybersecurity Certificate](https://www.coursera.org/professional-certificates/google-cybersecurity) on Coursera, a 60 hour, eight-course programme covering the fundamentals needed for entry-level security roles such as SOC analyst.

## Skills Acquired

### Security Fundamentals
- The eight CISSP security domains and the CIA triad (confidentiality, integrity, availability)
- Security frameworks and controls, including the NIST Cybersecurity Framework
- Risk assessment and security ethics

### Networking
- How networks and common protocols work
- Firewalls, network hardening, and defending against common network attacks
- Analysing network traffic

### Linux and SQL
- Navigating and managing Linux from the command line
- Filtering and searching files and logs
- Querying databases with SQL to support investigations

### Threats and Vulnerabilities
- Identifying and classifying assets, threats, and vulnerabilities
- Threat modelling and vulnerability assessment
- Cryptography and authentication fundamentals

### Detection and Response
- Intrusion detection and monitoring
- Log analysis and SIEM tools
- Incident response processes and using playbooks

### Automation
- Writing Python to automate repetitive security tasks
